# CipherCraft 2.0.1

- Source deletion now requires an explicit successful operation, including when filenames contain “Successfully”.
- File output uses atomic replacement and rejects input/output hard-link aliases.
- Rail Fence and columnar-transposition file operations preserve independent line boundaries and line endings.
- Analyzer decryptions preserve Unicode and use the same cipher rules as encryption.
- Caesar shift 0 works through Analyze, Apply and Decrypt, including known-plaintext analysis.
- Short Vigenère input shows an explanation instead of applying an invalid keyword.
- Analysis runs in the background, discards obsolete results and reports errors visibly.
- Affine keys normalize negative multipliers consistently; known-plaintext analysis rejects punctuation-only input.
- Relative analysis scores are explicitly labeled as comparisons, not probabilities.

Old multiline transposition ciphertext with lost line boundaries still needs the original file or external boundary information. Existing cipher conventions for whitespace removal and columnar X padding remain.

## Previous release: CipherCraft 2.0.0

CipherCraft is a free educational desktop toolkit for six historical ciphers.

## What's new

- Refreshed macOS and Windows GUI using CipherCraft's navy, teal, blue, and green palette.
- More legible headers, consistent field/button styling, a resizable results pane, and clear Text/File input modes.
- Caesar, Vigenère, Substitution, Transposition, Rail Fence, and Affine encryption and decryption.
- Key suggestions using local statistical cryptanalysis — no account or external AI API needed.
- Safer file handling: no automatic bulk deletion; deleting a source file requires an explicit choice.
- Corrected Rail Fence and columnar transposition algorithms, stronger validation, and cross-platform testing.

## Download and launch

Download `ciphercraft-macos.zip` for macOS or `ciphercraft-windows.zip` for Windows. Unzip the release asset, then launch `cipher_gui.app` (macOS) or `cipher_gui.exe` (Windows). The `cipher_tool` executable provides an interactive CLI.

**macOS:** This open-source build is not Apple-notarized. Gatekeeper may block initial launch. If you trust the downloaded release, go to System Settings → Privacy & Security → Open Anyway after attempting to open the app. Do not disable Gatekeeper system-wide.

**Compatibility:** This version corrects previously defective Rail Fence and columnar transposition encryption. Old ciphertext generated by defective versions may not decrypt with the corrected algorithms. Keep old keys and ciphertext.

**Security:** Classical ciphers are educational. They are not suitable for protecting confidential information.
